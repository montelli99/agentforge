AGENTFORGE / START HERE

Install it, then prove it works.

AgentForge runs locally first. Start with the public source, launch the control plane, and complete a harmless local verification before connecting models, channels, or execution providers.

Prerequisites

  • Node.js 22 or newer
  • Git
  • pnpm 10 or newer
  • Docker is optional

Windows PowerShell

git clone https://github.com/montelli99/agentforge.git
cd agentforge
corepack enable
pnpm install --frozen-lockfile
pnpm vnext

macOS or Linux

git clone https://github.com/montelli99/agentforge.git
cd agentforge
corepack enable
pnpm install --frozen-lockfile
pnpm vnext

Open the control plane

Visit http://127.0.0.1:3460. The default workspace starts empty. The setup guide can prepare the coordinator, workflow engine, JEv router, and goal-specific roles without connecting an outside account.

Run the first verification

pnpm typecheck
pnpm test:product-isolation
pnpm test:package:surface

A successful run proves the local code and public package boundary. It does not claim a channel, model provider, or Docker session is live.

Optional Docker execution

Configure an absolute repository path and approve a bounded plan before enabling Docker. The default installation stays offline and fail-closed.

Provider setup

Telegram uses BotFather. Discord uses the Developer Portal. Slack uses Socket Mode. Provider credentials never belong in the public repository.
