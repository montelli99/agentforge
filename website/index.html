From intent to a reviewable result

Automation with an accountable path back to people.

AgentForge’s purpose is not to hide work behind a model. It preserves the original goal, uses a bounded context packet, selects a capable route, and records what happened before a person accepts an outcome.

Setup guide agentFinds missing decisions and prepares a safe first workspace.
Operational memoryScopes reusable context to the workspace and project that need it.
Model routerUses capability and cost boundaries instead of pretending every model fits.
Quality flywheelCaptures corrections, drift signals, and evidence for repeatable improvement.
Channel mirrorMaps channels and subgroups to canonical spaces, with explicit ownership.
Procedure compilerTurns approved operating procedures into roles, steps, and reviewable revisions.
Browser operatorUses fresh observations, explicit handoff, and consent-aware actions for browser work.
Isolated executionKeeps approved work bounded to a declared repository, plan, and evidence trail.
Evidence and approvalsConnects results, checks, and authority to the work that produced them.

Built for an honest public release

Private by default.
Explicit when connected.

The open-source package is generic: it starts locally, includes no personal workspace data, and keeps external channels, models, or execution providers off until a user deliberately configures them.

LOCAL-FIRST Durable workspace state stays under the operator’s control.
APPROVAL-GATED Consequential work needs a reviewable authority boundary.
PROVIDER-NEUTRAL Channel and model adapters are opt-in extensions.
