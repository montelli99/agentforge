Execution Contract Engine (SOP ≠ Authority)

Core Architectural Law: An SOP describes work, but never grants authority. All agent execution runs within isolated Git worktrees under strict contract boundaries.

Sections 3, 4, 21, 22, 30, 31

🚫 Zero Production Write

Workers cannot execute outside their temporary Git worktree branch (`git worktree add`). Symlinks escapes fail closed.

🛑 Privileged Operation Gates

File deletion, outbound HTTP, force-pushes, and deploy commands instantly trip a Human Approval Request.

📋 Process-to-Agent Governance

Step-by-step SOP execution captures a typed `ProcessExecutionTrace` and validates every rule before proceeding.

⚖️ Anti-Spoon-Feeding Law

Model workers have 0 authority to mark tasks COMPLETE. Only the independent CompletionEngine can issue completion seals.
